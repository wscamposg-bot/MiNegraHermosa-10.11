# Nuestra Historia Sideral 💜

Web estática romántica de aniversario, hecha con HTML, CSS y JavaScript vanilla. Abre `index.html` directamente en un navegador; no requiere servidor ni instalación.

## Fotos

Coloca las imágenes opcionales en `assets/img/`:

- `entrada.jpg` (si no está, se intenta `boleta.jpg`)
- `boleta.jpg` (respaldo de la entrada)
- `qr-entrada.jpg` — imagen del código QR; aparece al girar el boleto
- `foto1.jpg` — Primera Cita
- `foto2.jpg` — Nosotros bien bonitos
- `foto3.jpg` — Piscilago
- `foto4.jpg` — Útica
- `foto5.jpg` — Soatá
- `foto6.jpg` — Viotá
- `foto7.jpg` — Nuestras Salidas
- `foto8.jpg` — Siempre Juntos

Si una imagen no está disponible, se muestra un placeholder sideral morado en su lugar.

## Personalización

Edita las preguntas y respuestas, la carta y los textos de la galería en `js/data.js`.
